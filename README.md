# AI 短剧导演 · Claude Skill

把「小说 → AI 视频分镜」的产品级制作流程，固化成一套可复用、可质检的工作流。

面向漫剧 / 真人短剧 / 混合型三条风格路线，解决 AI 短剧生产中真正卡人的问题：**不是不会写提示词，而是生成的镜头串不起来。**

---

## 它解决什么问题

用 AI 生成视频，单看每一镜都不错，拼起来却是一堆无法衔接的片段：

| 典型缺陷 | 根因 |
|---|---|
| 人物瞬移、空间逻辑崩 | 没有场景坐标锚点，每镜重新描述场景 |
| 跳帧（位置跳 / 光线跳 / 情绪跳） | 镜头之间没有继承约束 |
| 同一角色前后声线不一致 | 音色没有锁死，TTS 每次自由发挥 |
| 换个镜头就换衣服 | 服装规范没有独立成节 |
| 每镜重复写负向提示词，还老漏 | 全局负向词没有前置 |
| 漏拍、重拍、台词对不上 | 没有工业化的镜头覆盖检查 |

本 skill 把**导演思维**固化成可执行的工作流 —— 每一镜提示词都必须考虑上一镜的尾帧、角色的音色连续性、场景的空间坐标。

---

## 核心设计

- **🔄 镜头衔接约束** — 每镜 8 项继承检查：场景 / 站位 / 动作 / 表情 / 声音 / 服装 / 光线 / 首尾帧
- **🎙 音色锁死** — 角色音色总表 + 逐镜台词语调曲线，保证同一角色全片声线一致、只有情绪变化
- **⛔ 全局负向提示词前置** — 每镜直接引用，不重复书写、不漏项
- **🔢 图号对照表** — 角色 / 场景 / 群演分开编号，生成时只引用「图 1」，降低提示词冗长、提升一致性
- **📍 场景坐标锚点 + 布局地图** — 同一场景多镜不出现「人物瞬移」
- **🪝 钩子系统** — 开场钩 / 中段钩 / 结尾钩，短剧的留存命脉
- **✅ 镜头覆盖检查表 + 违禁词清单** — 工业化质检，规避 AI 视频审核红线

---

## 工作流：6 阶段 18 步骤

| 阶段 | 内容 |
|---|---|
| 1 | 小说分析与风格方向（视觉风格 / 色彩基调 / 镜头语言三选一确认） |
| 2 | 角色设计与音色锁定（角色三视图、音色总表、服装统一规范） |
| 3 | 场景设计与坐标锚点（锚点图、坐标系统、四视角摄影、出场退场协议） |
| 4 | 剧本拆解与分镜规划（小说→剧本转化、钩子系统、台词时长验证、镜头拆分） |
| 5 | 分镜提示词工程（全局前置定调、单镜模板、衔接约束、负向词、音色锁、转场、色彩分级） |
| 6 | 质检与输出（必检清单、生成统计、两章测试策略） |

> **两章测试 → 全本策略**：先用两章跑通全流程验证物料模板，确认无误再处理全本，避免全本返工。

## 安装

把 `SKILL.md` 放进 Claude Code 的 skills 目录：

```bash
# 用户级（对所有项目生效）
git clone https://github.com/<your-name>/ai-short-drama-director.git \
  ~/.claude/skills/ai-short-drama-director
```

或者手动把 `SKILL.md` 复制到 `~/.claude/skills/ai-short-drama-director/` 下。

## 使用

触发方式（提供任意一种即可）：

- 给一段小说 / 剧本，要求拆解为 AI 视频分镜
- 提到「AI 短剧」「分镜」「图生视频」「角色三视图」
- 要求生成 AI 视频的提示词物料

skill 会先做两章测试，确认物料模板后再全本推进。
